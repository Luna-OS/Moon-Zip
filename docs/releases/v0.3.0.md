Archives that come in several parts now work as one archive.

## Download
- **Moon-Zip-Setup-0.3.0.exe**: installer. Installs per user, no admin rights needed. It updates an older version in place.
- **Moon-Zip-0.3.0-win-x64.zip**: portable version.

The builds are not code-signed, so Windows SmartScreen warns the first time you start them. Click "More info" and then "Run anyway".

## New
- **Archives in parts** such as `Game.part1.rar` … `Game.part5.rar` (also `name.7z.001` …, `name.rar` + `name.r00` …, and split ZIPs with `name.z01` …) are one archive in Moon Zip. See [docs/multi-part.md](https://github.com/Luna-OS/Moon-Zip/blob/main/docs/multi-part.md).
  - **Any part opens the whole archive**; the title bar shows how many parts it has.
  - **Select all the parts and extract once**: "Extract here", "Extract to new folder", "Extract to…" and "Test archive" run once for the set instead of once per part, and the new folder is named after the archive, without `.part1`.
  - **Dropping all the parts** on the start page opens the archive.
  - **Missing parts are named** before anything is extracted ("A part of this archive is missing: Game.part3.rar"), and an archive whose last parts are missing says that it ends too early.
