Moon Zip now works hand in hand with Moon Explorer.

## Download
- **Moon-Zip-Setup-0.2.0.exe**: installer. Installs per user, no admin rights needed. It updates 0.1.0 in place.
- **Moon-Zip-0.2.0-win-x64.zip**: portable version.

The builds are not code-signed, so Windows SmartScreen warns the first time you start them. Click "More info" and then "Run anyway".

## New
- **Moon Explorer instead of Windows Explorer.** When [Moon Explorer](https://github.com/Luna-OS/Moon-Explorer) is installed, Moon Zip uses it wherever it used Windows Explorer: extracted files open in a new Moon Explorer tab, "Show in Moon Explorer" after a right-click action shows the result (a new archive selected in its folder), and Moon Explorer's own Open, Save and folder dialogs pick archives, extract folders and where to save new archives (Moon Explorer 0.3.0 or later). Without Moon Explorer, everything stays with Windows Explorer. See [docs/moon-explorer.md](https://github.com/Luna-OS/Moon-Zip/blob/main/docs/moon-explorer.md).
- **The files show up after extracting**, after the right-click menu's "Extract here" and "Extract to new folder" too.
- **Settings**: "Use Moon Explorer instead of Windows Explorer" and "Show the files after extracting", both on by default.
